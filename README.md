# portfolio

Contains all the portfolio details of me. This uses no special tech stack and relies on just plain HTML, CSS and JavaScript.

Live at **https://www.kcsufal.com.np** (GitHub Pages, served from the `main` branch root).

## Structure

- `index.html`: the single-page portfolio
- `styles.css`: all styles (dark/light themes via `data-theme`)
- `script.js`: carousels, typewriter, theme toggle, Medium feed, contact form, honors modal
- `404.html`: custom not-found page
- `assets/img/`: images (WebP, already resized; keep new images small)
- `assets/img/projects/`: project thumbnails (placeholders; replace with real screenshots at ~800×520)

## Adding images

Keep images close to their display size. Logos display at 40px (use ~160px files), honors at 120px and up to 450px in the popup (use ~900px files).
